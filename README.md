# Q学習によるロボットの移動制御
### ～学習した行動をROS 2・Gazeboで再現する～

## 1. 概　要

強化学習の一種であるQ学習を用いてロボットの移動行動を学習し、その結果をROS 2とGazeboの3Dシミュレーション環境で再現しました。

具体的には、5マスで構成された簡易的な1次元環境において、ロボットがゴールに向かう行動をQ学習によって習得します。その後、学習した行動に基づいてROS 2から速度指令を送信し、Gazebo上の緑色の差動二輪ロボットを前進させます。

これにより、強化学習による行動の学習から、ロボットシミュレーション上での動作再現までの一連の流れを確認しました。

## 2. 使用技術・開発環境

自宅のWindows PCにWSL2を導入し、Ubuntu上でROS 2とGazeboを使用しました。

ホストOS： Windows 10 Home

Linux環境： WSL2（Windows Subsystem for Linux 2）

Ubuntu： 22.04

プログラミング言語： Python 3

AI技術： Q学習（強化学習）

ロボット制御： ROS 2 Humble

3Dシミュレータ： Gazebo Fortress 6.18.0

ROS 2とGazeboの連携： ros_gz_bridge

開発環境の工夫

Windows 10 Homeの自宅PC上にWSL2を構築し、Ubuntu 22.04でROS 2 HumbleとGazebo Fortressを動作させました。

また、ROS 2とGazebo間の通信トピックを適切に設定することで、Pythonプログラムから送信した速度指令によって、Gazebo上の差動二輪ロボットを前進・停止させることができました。

## 3. 主なファイル

| ファイル | 内容 |
|---|---|
| `q_learning.py` | Q学習の実行 |
| `q_table.json` | 学習結果の保存 |
| `q_gazebo.py` | 学習した行動のGazeboでの再現 |
| `q_control.py` | 移動制御に関するプログラム |
| `mamori_demo.sdf` | Gazeboの3Dシミュレーション環境 |

## 4. 動作の仕組み

1. Pythonで5マスの簡易環境を使ってQ学習を実行します。
2. 学習結果を `q_table.json` に保存します。
3. Gazeboでロボットとゴールの目印を表示します。
4. ROS 2の速度指令を使い、学習した移動行動をロボットで再現します。

※ 学習した行動を再現するデモです。カメラやセンサーでゴールを認識して自律走行する仕組みではありません。

## 5. 実行方法

ROS 2 HumbleとGazebo Fortressを使用できる環境で、Gazeboを起動します。

```bash
ign gazebo mamori_demo.sdf
```

別のターミナルでROS 2とGazeboを接続します。

```bash
ros2 run ros_gz_bridge parameter_bridge /model/vehicle_green/cmd_vel@geometry_msgs/msg/Twist@ignition.msgs.Twist
```

さらに別のターミナルで移動プログラムを実行します。

```bash
python3 q_gazebo.py
```

## 7. 工夫した点

Q学習による行動の学習と、ROS 2・Gazeboによるロボットの移動シミュレーションを組み合わせました。

5マスの簡易的な1次元環境を用意し、Q学習の仕組みを理解しやすくしました。

学習結果を q_table.json に保存し、学習処理とロボットの動作再現を分けました。

ROS 2の速度指令をGazeboに送信し、学習した行動を3D空間のロボットの動きとして確認できるようにしました。

緑色の差動二輪ロボットと赤いゴールの目印を配置し、動作を視覚的に分かりやすくしました。

## 8. 動作確認の結果

Gazebo上で緑色の差動二輪ロボットが前進し、プログラムの動作終了後に停止することを確認しました。

また、ROS 2とGazeboを接続するブリッジのトピックをロボット専用の /model/vehicle_green/cmd_vel に合わせることで、速度指令が正しく伝わるようになりました。

## 9. 課題と今後の改善

現在のプログラムは、簡易環境で学習した行動を一定時間の速度指令として再現する方式です。

そのため、障害物の検知や、カメラ・センサーによるゴールの認識、周囲の状況に応じたリアルタイムの経路変更には対応していません。

今後は、センサー情報をQ学習の状態として利用し、障害物を回避しながらゴールへ移動できる仕組みに発展させたいと考えています。

## 10. まとめ

Q学習で得られた行動をROS 2の移動指令としてGazebo上で再現することで、強化学習とロボットシミュレーションの連携を学びました。
